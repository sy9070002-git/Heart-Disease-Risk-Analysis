# ❤️ Heart Disease Analysis

## 📌 Project Overview
This project performs an end-to-end analysis of heart disease data to identify major health risk factors and generate actionable insights. The analysis combines Python for Exploratory Data Analysis (EDA), SQL for analytical querying, and Power BI for interactive dashboard visualization.

---

## 🎯 Objectives
- Analyze patient health records to identify heart disease risk factors.
- Perform data cleaning and preprocessing.
- Solve business-oriented analytical problems using SQL.
- Build an interactive Power BI dashboard for decision-making.
- Present insights through meaningful visualizations and KPIs.
